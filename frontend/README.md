# Frontend

Simple React UI for the Financial News Intelligence System.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Requirements

- Node.js 18+
- Backend running at http://localhost:8000

## Features

- 🔍 **Query**: Search financial news with natural language
- 📥 **Ingest**: Add articles to the system
- 🎮 **Demo**: Run demo with sample articles
- 📊 **Stats**: View system statistics
- 📝 **Markdown**: Beautiful rendering of LLM responses
